# partnersim-dynet

Agent-based dynamic partnership network simulation in Python.

`partnersim-dynet` simulates evolving partnership networks for sexual-health,
demographic, and social-network research. Agents form and break partnerships
over discrete timesteps based on configurable formation and breakage
probabilities stratified by sex, sexual orientation, and age group.
